# 血契蚊子：女帝别拍扁我 剧本创作规格

## 目标
- 交付类型：竖屏短剧
- 集数/段落数：60
- 单集/单段时长：约3分钟
- 原素材：原创设定/用户口述大纲

## 用户要求
参照红果短剧「重生成蚊子×契约女帝」类爽点节奏，创作原创竖屏短剧（非照搬原作人名与具体剧情）。
- 格式：vertical_short_drama
- 集数：60集（完整，不得省略合并）
- 每集：约3分钟；对白驱动；每集至少一个爽点/反转；集尾必须有钩子
- 语言：中文（zh）
- 输出：dramas/血契蚊子-女帝别拍扁我/

## 核心设定（原创）
- 男主林朝：高三普通生，一觉醒来变成白纹伊蚊，绑定【血脉进化系统】——吸血积气血，达标即进化。
- 女主苏倾城：前世帝级御兽师，因第一只契约兽血脉过低、根基不稳，陨落于天劫；重生回十八岁，倾家荡产买高级血脉灵青蟒准备血契，仪式关键时刻被蚊子吸了一口，被迫与林朝血契同生共死。
- 世界：灵武复苏后的都市+御兽学院；公开御兽体系，暗面有「惊蛰公会」猎杀高血脉。
- 主线爽点：蚊子逆袭进化 / 女帝被迫养蚊 / 系统吸血升级 / 校园打脸 / 秘境夺宝 / 公会追杀 / 虫族觉醒 / 双人共主。

## 人物
- 林朝（男主/蚊子形态为主，后期可短暂人形投影）：嘴贱冷静，怂里带刚。
- 苏倾城（女主）：冷艳决绝，重生女帝气场；嘴上嫌弃蚊子，关键时刻护契约。
- 赵无咎：同班纨绔，仰慕苏倾城，处处针对「废物契约兽」。
- 沈寒星：惊蛰公会少主，前世与女帝有因果。
- 系统（旁白/字幕弹窗）：冷幽默播报。

## 改编边界
- 原创IP，禁止照搬既有小说/短剧的具体对白、章节标题与专有情节链。
- 每集必须有可见冲突和集尾继续看的理由。
- 内心戏转成可演的动作、对白、系统字幕、物件或场面后果。

## 源素材摘要
用户口述需求：红果短剧风格，重生蚊子+契约女帝，60集×约3分钟；不调用用户云端API，直接落盘原创剧本。

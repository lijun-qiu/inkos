# 重生回到末日前，我干翻一切 剧本创作规格

## 目标
- 交付类型：通用剧本
- 集数/段落数：100
- 单集/单段时长：3分钟
- 原素材：original idea

## 用户要求
创作100集横屏短剧剧本，每集约3分钟（约800-1000字场景描述+对白）。 标题：重生回到末日前，我干翻一切 核心设定： - 主角在怪物末世降临后死去，重生回到末世降临前 - 利用前世记忆疯狂囤积物资、提前寻找觉醒超能力的方法 - 妹妹（妹控属性），死党好兄弟 - 从末世降临前准备期写到末世初期爆发，囤物资与超能力觉醒双线并行 末世类型：怪物（怪物肆虐的末世） 超能力体系：混合体系（元素系+肉体强化+精神系等多元超能力） 对白风格：幽默、接梗、不废话，节奏明快 剧本格式：横屏短剧（场景描写+对白，每集3分钟体量），共100集 输出目录：dramas/

补充要求：
横屏短剧，100集，每集3分钟（约800-1000字场景+对白）。怪物末世重生题材，主角囤物资+觉醒混合超能力（元素系+肉体强化+精神系），妹控属性+兄弟情。对白风格幽默接梗不废话，节奏明快。从末世降临前准备期写到末世初期爆发。

## 改编边界
- 优先保留用户明确指定的人物、关系、冲突、关键事件和禁忌。
- 不替用户擅自决定“忠实改编 / 商业强化 / 低成本拍摄”等强度；只执行用户已确认的规格。
- 如果原素材是小说，内心戏要转成可演的动作、对白、证据、物件或场面后果。
- 如果目标是短剧，每集必须有可见冲突和集尾继续看的理由。

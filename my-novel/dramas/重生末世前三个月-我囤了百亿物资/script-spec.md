# 重生末世前三个月，我囤了百亿物资 剧本创作规格

## 目标
- 交付类型：竖屏短剧（红果节奏）
- 集数/段落数：50（本期先交付前10集）
- 单集/单段时长：约2–3分钟
- 原素材：short_story

## 用户要求
把短篇小说《重生末世前三个月，我囤了百亿物资》改编为红果风格竖屏短剧。
- 格式：vertical_short_drama
- 全集：按原作第1–50章，一章一集，共50集（已完成）
- 每集：约2–3分钟；对白驱动；每集至少一个爽点/反转；集尾必须有钩子
- 保留：重生、囤货、妹控、兄弟情、黑蛇仇恨、进化原液、进化计划、零号终战
- 语言：中文（zh）
- 输出：dramas/重生末世前三个月-我囤了百亿物资/
- 旧版长剧本备份：drafts/v001-full-50ep.md；红果完整版：drafts/v002-hongguo-full-50ep.md

## 改编边界
- 忠实原作主线人物与关键事件，压缩清单式囤货为可演场面
- 内心戏转成动作、对白、闪回、字幕倒计时
- 不弱化黑蛇威胁；第10集尾留继续看的钩子

## 源素材摘要
林北末世第五年被黑蛇处决后重生，倒计时90天：彩票起家、说服兄弟、唤醒妹妹、改建堡垒、抢购物资、与黑蛇截胡冲突、夜袭偷进化原液、水泥厂对峙换暂时停战。

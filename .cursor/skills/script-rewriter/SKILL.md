# 剧本改写指南（火宝格式）

来源：`huobao-drama/skills/script_rewriter`。在 inkos 内用**本地读章 → 改写 → 写文件**，不调用火宝 API。

## 改写原则

1. **保留核心情节**：不改变主线故事和角色关系
2. **增强画面感**：将叙述性文字转化为可视化的场景描写
3. **对话驱动**：用对白推动情节，减少旁白
4. **节奏把控**：每场戏控制在 30-60 秒，适合短视频
5. **不写镜头语言**：不涉及景别、角度、运镜，这些属于分镜拆解步骤

## 格式化剧本格式

```
## S01 | 内景 · 咖啡厅 | 黄昏

黄昏的光线透过落地窗洒进咖啡厅，吧台上咖啡杯热气升腾。

小明独自坐在角落卡座，低头看手机，神情有些焦虑。

门铃响起，小红推门而入。她看到小明，微笑着走过去。

小红：（微笑）等很久了吗？
小明：（抬头）还好，刚到。
```

### 格式规则

- `## S编号 | 内景/外景 · 地点 | 时间段` — 场景头
- 动作描写自然段 — 不包含任何镜头语言
- `角色名：（状态/表情）台词内容` — 对白格式

### 内容量参考（高密度）

- 相对小说本章：**充分场景化**，关键情绪/冲突必须拍满，禁止「一笔带过」式大纲感
- 单集通常 **6–12 场**（开篇死亡闪回、对峙、觉醒等可拆细）；每场有可演动作与情绪转折
- 感官与物件细节要落地（声音、气味、触感、手机屏、血迹等），但**禁止**重复同一句凑字
- 格式化增量来自拆场与可演化，不是注水旁白堆砌

### 密度标杆

以「处决场完整演出 → 醒来呕吐扇耳光 → 备忘录/彩票/窗景/清单/两通电话」这一级颗粒度为准，不要压成 3–4 个快切场。

## 改写步骤（inkos 本地 · 必须串行）

对第 N 集（**改完 N 才能开 N+1**）：

1. **读上一集已改剧本结尾**（N≥2）：`huobao/episodes/ep{N-1:02d}.md` 末 1–2 场  
2. **读上一章小说原文**（可选加强）：`final/chapters/{N-1:04d}.md` 末尾  
3. **读本集原文**：`final/chapters/{N:04d}.md`  
4. 按高密度格式改写；开场承接上一集剧本收束  
5. **写入** `huobao/episodes/ep{N:02d}.md` 后，再开始下一集  

禁止「50 集同时开写」的裸并行。若必须加速：也只能在**上一集文件已落盘**后启动下一集。

## 注意事项

- 心理描写可转化为角色表情/动作或短自语/画外音
- 长段叙述拆分为多个短场景
- 确保每个场景有明确的情绪转折点
- 保持角色语言风格一致性
- 场景编号连续递增（S01, S02, S03...）；**每集从 S01 重新开始**
- 时间段要具体（黄昏、深夜、清晨），不要笼统写「白天」

## 跨集衔接（第 2 集起）

**优先**附带上一集**已改剧本**结尾（场面级硬咬合）；小说上一章原文作情节校对：

1. 先读懂上一集剧本收束：人物位置、情绪、未完成动作
2. 本集开场自然过渡，不要重讲上一集已演完的情节
3. 角色称呼、关系、已揭示信息保持一致
4. 若尚无上一集剧本，再退回上一章小说原文末尾
